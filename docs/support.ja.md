# Terra Draw コミュニティを支援する

コミュニティを育てていくには、みなさんの支援が欠かせません。Terra Draw を気に入っていただけたら、ぜひリポジトリにスターを付けたり、フォークしたりしてください。

プロジェクトへの貢献のためのプルリクエストも、いつでも歓迎しています。

## バグ報告・機能リクエスト

バグを見つけた場合や、Terra Draw やプラグインの改善案がある場合は、対象のリポジトリで issue を作成してください。
