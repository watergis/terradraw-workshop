# Terra Draw の応用機能

このセクションでは、4 つの演習を通じて Terra Draw の応用的な機能を学びます。

## スタイルのカスタマイズ

Terra Draw のモードごとに、色・線幅・不透明度・破線パターンなどのスタイルを変更する方法を学びます。

## イベント処理

この演習では、Terra Draw のイベントを処理する方法を学びます。

## データ管理

Terra Draw でのデータの扱い方 (データの読み込み、取得、削除) を学びます。

## 元に戻す / やり直す

Terra Draw の新しい履歴機能 (v1.26 で追加) を有効にし、Undo / Redo ボタンとキーボードショートカットに結び付ける方法を学びます。
